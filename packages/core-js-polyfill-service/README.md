# @core-js/polyfill-service

Serves each visitor a [`core-js`](https://github.com/zloirock/core-js) bundle built for their
browser: the engine is detected from the request, the bundle carries the modules that engine
actually needs, and the script tag is injected into the HTML response.

**In development.** The public API is not settled yet and the package is not published.

# @core-js/bundle

The pre-built browser bundle of the library, plain and minified.

## Target environment

The bundles hold the runtime baseline of `packages/core-js` - engines about IE11 - because they ARE that library, built.

## What is here

`index.js` and `minified.js` are generated by `npm run bundle-package` (`scripts/bundle-package/`) and never edited in place - an edit is lost on the next build. Hand-written: `README.md`, `package.json`, `.npmignore`; `LICENSE` is distributed by the copy step of `npm run prepare`.
